# Library Management System

A Java-based Library Management System designed to manage books and library members.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)

## Project Structure

```text
LibraryManagementSystem/
├── src/
│   ├── Book.java
│   ├── Library.java
│   ├── Member.java
│   └── Main.java
├── .gitignore
└── README.md
```

## Classes

- **Book** – Represents a book in the library.
- **Library** – Manages library operations.
- **Member** – Represents a library member.
- **Main** – Contains the main method and starts the application.
